# Fluent Panda — мини-приложение для изучения языков

Приложение в `index.html` работает без сборки. Разместите всю папку на статическом HTTPS-хостинге, например GitHub Pages, и укажите её адрес в настройке `WEBAPP_URL` бота. Прогресс хранится локально и частично синхронизируется через Telegram CloudStorage. При большом объёме состояния синхронизация может не выполниться — храните копию данных и проверяйте на своих устройствах.

## Premium и промокоды

Для покупки и проверки Premium в приложении необходим запущенный API бота. В файле `api-config.js` задайте публичный HTTPS-адрес API (без `/api`) и повторно опубликуйте сайт. Не добавляйте туда токен бота или другие секреты. Инструкция по развёртыванию API — в README архива FluentPandaBot.

Без доступного API приложение не сможет подтвердить Premium, даже если он куплен; в боте статус и `/promo КОД` работают отдельно. В Telegram данные пользователя проверяются сервером по подписи, а не по параметру URL или сохранённому флагу. Платный контент остаётся в исходном HTML и не является скрытым от просмотра; для защиты контента нужен сервер.

Напоминания в приложении локальные и работают, пока оно открыто. Сообщения Telegram настраиваются отдельно через `/remind` у бота.

## Озвучка

Для генерации файлов: `pip install edge-tts`, затем `python tools/gen_audio.py`. Появится папка `audio/`; если её нет, используется голос браузера.
